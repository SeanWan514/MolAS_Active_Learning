The upstream website and official documentation were checked on 2026-10-31. The subsequent author confirmation resolves the publication authorization for this GitHub release. Historical model revisions and missing independently retrieved license documents remain recorded as provenance limits, rather than current requests for permission. The project's MIT license applies to its original software; the separate dataset release should state its actual component terms. The [Hugging Face license documentation](https://huggingface.co/docs/hub/repositories-licenses) describes metadata and does not assign a license to source material.

The large structural graph inputs remain excluded from Git and will be published separately. Add their actual versioned dataset reference and applicable attribution when that release is available.
